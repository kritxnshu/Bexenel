# BEXENEL

> Hello world, something is coming.

A sleek, modern coming-soon web page for **BEXENEL**.

## Features

- **Typography & Aesthetics**: Minimalist luxury dark theme with dynamic typography (`Syne`, `Outfit`, `Space Grotesk`).
- **Interactive Stardust Canvas**: High-DPI ambient particle constellation on HTML5 canvas.
- **Spotlight & 3D Tilt**: Mouse-following dynamic lighting and interactive 3D perspective tilt on the brand title.
- **Responsive**: Fluid typography and layout scaling across all devices and screen sizes.
